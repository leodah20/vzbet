# Casos de uso

## Torcedor
- Cadastrar-se e fazer login
- Ver times, jogadores e a tabela de jogos de um campeonato
- Enviar um palpite de placar para uma partida agendada (até o horário do jogo)
- Editar seu palpite até o horário do jogo
- Ver o ranking geral

## Admin
- Cadastrar times e jogadores
- Cadastrar campeonatos
- Agendar partidas (associando times e campeonato)
- Cancelar uma partida agendada
- Lançar o resultado de uma partida finalizada (dispara o cálculo de pontos de todos os palpites daquela partida)
